# Skill: internship-search

## Objective

Find recently posted PFE / final-year internship opportunities relevant to
software engineering, AI, web development, cloud, and DevOps in Morocco.

## Search categories

### Software

```text
PFE Software Engineer Morocco
PFE Software Developer Maroc
stage fin d'études software engineer Maroc
```

### Backend

```text
PFE Backend Morocco
PFE Java Spring Boot Morocco
stage PFE Java Maroc
```

### Full Stack

```text
PFE Full Stack Morocco
PFE React Morocco
PFE Next.js Morocco
```

### DevOps

```text
PFE DevOps Morocco
PFE Docker Kubernetes Morocco
PFE Cloud Morocco
```

### AI

```text
PFE Artificial Intelligence Morocco

```

## LinkedIn

Search indexed pages rather than implementing authenticated scraping.

```text
site:linkedin.com/jobs "PFE" Morocco
site:linkedin.com/jobs "Software Engineer Intern" Morocco
site:linkedin.com/posts "PFE" Morocco
site:linkedin.com/posts "PFE" "Java" Maroc
site:linkedin.com/posts "stage fin d'études" DevOps Maroc
```

Differentiate:

```text
linkedin.com/jobs/
```

from:

```text
linkedin.com/posts/
```

## Indeed

Preserve Indeed URLs when found.

## ReKrute

Preserve ReKrute URLs when found.

## Company Careers

Prefer the official company career page as the main application URL when
available, but preserve aggregator URLs too.

## Freshness

Prefer recently posted roles.

Never invent a posting date when a provider does not expose one.
